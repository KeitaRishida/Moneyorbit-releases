# Money Orbit — Android Updates

This is the **public APK releases repository** for Money Orbit.

Only signed Android app packages and corresponding SHA-256 checksums are published here. The full application source code and private build/signing credentials remain in a separate private repository.

## Updating

Open the [Releases page](https://github.com/KeitaRishida/Moneyorbit-releases/releases), select the latest appropriate release, and download `MoneyOrbit-phone.apk`, or use **More → Update channel → Beta → Check for updates** inside the Money Orbit app once that updater is configured.

Android requires your approval before installing updates. Do not uninstall an existing permanently signed Money Orbit app when updating.

**Alpha/beta warning:** Money Orbit is under development. Its local financial SQLite database is not yet encrypted at rest. Do not depend on it as your only financial record.

This public repository contains no user accounts, financial ledgers or personal app backups.
